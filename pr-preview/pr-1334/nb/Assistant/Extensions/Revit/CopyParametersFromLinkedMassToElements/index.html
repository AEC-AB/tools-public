Copy Parameters From LinkedMass To Elements

Dette innholdet er ikke tilgjengelig på ditt språk.

Description

Section titled “Description”

This Revit extension automates the process of copying parameter values from mass elements in a linked Revit model to elements in the host model that intersect with those masses. This is particularly useful in conceptual design workflows where massing studies define zones or areas, and you need to transfer data (such as zone names, area types, or design options) to the actual building elements.

The extension detects spatial relationships between 3D mass geometry in a linked file and elements in your current model, then copies the specified parameter value from each mass to all intersecting elements.

Configuration

Section titled “Configuration”

Link

Section titled “Link”
  • Type: Dropdown selection
  • Description: Select the Revit link that contains the mass elements you want to use as the source for parameter values
  • What it does: The extension will automatically detect all loaded Revit links in your current project and display them by their file names in a dropdown list. Choose the link that contains your massing model
  • Requirements:
    • The link must be loaded in the current project (not unloaded)
    • The linked model must contain mass elements (Generic Models category: Mass)
    • The link document must be accessible

Parameter

Section titled “Parameter”
  • Type: Dropdown selection
  • Description: Select the parameter from the mass elements that you want to copy to intersecting elements in the host model
  • What it does: This dropdown automatically populates with all parameters that are available on mass elements in the linked model. The extension will read the value from this parameter on each mass and copy it to the same-named parameter on intersecting elements
  • Requirements:
    • The parameter must exist on the mass elements in the linked model
    • Elements in the host model must also have a parameter with the exact same name
    • The parameter should be a text-based parameter (the extension reads it as a string value)

Functionality

Section titled “Functionality”

Description

Section titled “Description”

The extension performs spatial analysis to identify which elements in your host model physically intersect with mass elements in a linked Revit file, then transfers parameter data from the masses to those intersecting elements.

Step-by-step process:

  1. Link Identification: The extension accesses the specified Revit link and retrieves its transformation matrix to correctly position the linked geometry in the host model’s coordinate system

  2. Mass Collection: Finds all mass elements in the linked model (elements in the Mass category that are not element types)

  3. Parameter Reading: For each mass, reads the value of the specified parameter

  4. Geometry Processing: Extracts the 3D solid geometry from each mass element and transforms it to the host model’s coordinate system

  5. Spatial Analysis: Uses Revit’s ElementIntersectsSolidFilter to find all elements in the host model that physically intersect with each mass’s geometry

  6. Parameter Transfer: For each intersecting element found, the extension:

    • Looks up a parameter with the same name as the source parameter
    • If found, copies the parameter value from the mass to the host element
    • Skips elements that don’t have a matching parameter

  7. Transaction Management: All changes are made within a single transaction, so they can be undone with one Undo command

How to Use

Section titled “How to Use”

Prerequisites

Section titled “Prerequisites”

  1. Prepare the Linked Model:

    • Create or open a Revit model with mass elements
    • Add a parameter to the mass elements (e.g., “Zone_Name”, “Space_Type”, or “Design_Option”)
    • Populate this parameter with the values you want to transfer
    • Save the model

  2. Prepare the Host Model:

    • Open the Revit model where you want to receive the parameter values
    • Link the massing model into this project (Insert > Link Revit)
    • Ensure the link is loaded and positioned correctly
    • Add a parameter with the exact same name to the elements that will receive the values (this can be a shared parameter or project parameter)

Configuration Steps

Section titled “Configuration Steps”

  1. Open Assistant and create or edit a sequence

  2. Add the Extension Task:

    • Add a new task to your sequence
    • Select “Copy Parameters From Linked Mass To Elements”

  3. Configure the Extension:

    • Link: From the dropdown, select the linked Revit file that contains your masses
    • Parameter: From the dropdown, select the parameter name you want to copy (this should show all parameters available on mass elements)

  4. Save and Run:

    • Save your sequence configuration
    • Run the sequence in Assistant
    • The extension will process all masses and their intersecting elements

Execution and Results

Section titled “Execution and Results”
  • Processing Time: Depends on the number of masses and elements (spatial analysis can take time for complex models)
  • Transaction: All changes occur in one transaction named “CopyParametersFromLinkedMassToElements”
  • Undo: You can undo all changes with a single Undo command (Ctrl+Z)

Verification

Section titled “Verification”
  1. Select an element that should have received a parameter value
  2. Open the Properties panel or Element Properties dialog
  3. Verify that the parameter has been populated with the correct value from the intersecting mass
  4. Check multiple elements to ensure the transfer worked as expected

Use Cases

Section titled “Use Cases”

Conceptual Design Zone Marking

Section titled “Conceptual Design Zone Marking”

Scenario: You have a massing study that defines different zones (residential, commercial, parking, etc.) and need to mark all structural and architectural elements with their respective zone names.

Workflow:

  1. In the massing model, add a “Zone_Type” parameter to masses and assign values like “Residential”, “Commercial”, “Parking”
  2. In the host model, add the same “Zone_Type” parameter to all relevant categories (walls, floors, columns, etc.)
  3. Run this extension to automatically tag all elements based on which zone mass they intersect

Design Option Tagging

Section titled “Design Option Tagging”

Scenario: You have multiple design options represented as masses and want to tag building elements that belong to specific options.

Workflow:

  1. Create masses for each design option and add a “Design_Option” parameter
  2. Add the same parameter to your building elements
  3. Use the extension to automatically propagate the design option information

Phasing Information Transfer

Section titled “Phasing Information Transfer”

Scenario: Mass elements represent different construction phases, and you need to mark elements with their phase information.

Workflow:

  1. Create masses with a “Construction_Phase” parameter
  2. Add the parameter to elements that need phasing information
  3. Run the extension to transfer phase data based on spatial location

Troubleshooting

Section titled “Troubleshooting”

Issue 1: No Parameters Appear in the Parameter Dropdown

Section titled “Issue 1: No Parameters Appear in the Parameter Dropdown”

Causes:

  • The linked model doesn’t contain any mass elements
  • Mass elements in the linked model don’t have any parameters
  • The link is not loaded or cannot be accessed

Solution:

  1. Verify the linked model is loaded (not unloaded) in the Manage Links dialog
  2. Open the linked model directly and confirm it contains mass elements (Category: Mass)
  3. Check that the masses have parameters defined (either project or shared parameters)
  4. Reload the link if necessary

Resources: Revit Help - Managing Links

Issue 2: Parameters Not Being Copied to Host Elements

Section titled “Issue 2: Parameters Not Being Copied to Host Elements”

Causes:

  • Host elements don’t have a parameter with the matching name
  • The parameter exists but is read-only
  • Elements don’t physically intersect with the mass geometry
  • The parameter type doesn’t support the value being copied

Solution:

  1. Verify the parameter exists on the host elements with the exact same name (case-sensitive)
  2. Check that the parameter is not read-only or a built-in parameter
  3. Verify spatial intersection by creating a 3D view and using transparency to see overlaps
  4. Ensure the masses have valid 3D solid geometry (not just surfaces or lines)

Resources: Revit API - Parameter Documentation

Issue 3: Extension Reports “Revit has no active model open”

Section titled “Issue 3: Extension Reports “Revit has no active model open””

Causes:

  • No Revit project is currently open
  • The active view is in a family editor, not a project

Solution:

  1. Open a Revit project file (.rvt)
  2. Ensure you’re not in family edit mode
  3. Activate a project view before running the extension

Issue 4: Some Elements Are Skipped

Section titled “Issue 4: Some Elements Are Skipped”

Causes:

  • Elements don’t physically intersect with any mass geometry
  • Mass geometry is invalid (zero volume)
  • Elements don’t have the target parameter

Solution:

  1. Check element locations relative to masses in a 3D view
  2. Verify mass geometry is valid solid geometry (use Mass > Show Mass Form and Floors)
  3. Ensure all target elements have the parameter added
  4. Consider masses may need to be slightly larger to ensure intersection

Issue 5: Wrong Values Are Being Copied

Section titled “Issue 5: Wrong Values Are Being Copied”

Causes:

  • Multiple masses overlap the same element
  • Parameter values in the linked model are incorrect
  • Link transformation is not correctly applied

Solution:

  1. When multiple masses intersect an element, the last processed mass wins (by design)
  2. Review and correct parameter values in the linked massing model
  3. Verify the link is positioned correctly in the host model
  4. Consider reorganizing masses to avoid overlaps if specific assignments are needed

FAQ

Section titled “FAQ”

Q: Can I use this extension with multiple linked models at once?

  • A: No, each execution of the extension works with one linked model at a time. If you need to process multiple links, add multiple instances of this extension task to your Assistant sequence, each configured for a different link.

Q: What happens when an element intersects with multiple masses that have different parameter values?

  • A: The element will receive the parameter value from the last mass that is processed. The extension processes masses sequentially, so if an element intersects multiple masses, each subsequent mass will overwrite the previous value. To avoid this, ensure your masses don’t overlap or use distinct masses for distinct zones.

Q: Does this work with any element category in the host model?

  • A: Yes, the extension checks all element categories in the host model (except element types). Any element that physically intersects a mass and has a matching parameter will receive the value, including walls, floors, columns, furniture, equipment, etc.

Q: Can I copy multiple parameters at once?

  • A: No, each execution copies one parameter. If you need to copy multiple parameters, add multiple instances of this extension to your sequence, each configured to copy a different parameter.

Q: What types of parameters are supported?

  • A: The extension reads the parameter value as text (AsString), so it works best with text parameters, but it can also handle parameters that can be converted to strings (like integers or yes/no parameters). Very large numbers or special formatting may not transfer correctly.

Q: Will this work if the linked model is not visible in my current view?

  • A: Yes, the extension works regardless of view settings or element visibility. It accesses the link and performs geometric analysis independent of what’s currently displayed.

Q: Can I undo the changes made by this extension?

  • A: Yes, all changes are made within a single Revit transaction. You can undo all modifications with one Undo command (Ctrl+Z).

Q: Do I need to have the linked model open while running this extension?

  • A: No, the linked model doesn’t need to be open. The extension accesses the linked document through the link instance in your host model.

Best Practices

Section titled “Best Practices”

  1. Test on a Small Sample First: Before processing your entire model, test with a small section or single mass to verify the parameter mapping works correctly

  2. Use Descriptive Parameter Names: Choose clear, consistent parameter names that won’t be confused with other parameters in your model

  3. Validate Geometry: Ensure mass elements have valid 3D solid geometry (not just surfaces). Use Revit’s analysis tools to check for invalid geometry

  4. Coordinate System Awareness: Verify your linked model is correctly positioned. The extension uses the link’s transformation, so incorrect link placement will result in incorrect spatial analysis

  5. Parameter Type Consistency: Use text or string-based parameters for most reliable results

  6. Document Your Workflow: Keep track of which parameters are being used for data transfer, especially in team environments

  7. Backup Before Batch Operations: When processing large models, save a backup before running the extension
