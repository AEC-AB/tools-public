Start AutoCAD

Dette indhold er ikke tilgængeligt i dit sprog endnu.

Overview

Section titled “Overview”

This guide will assist you in using the ‘Start AutoCAD’ task to open AutoCAD.

Step 1: Locating the Task

Section titled “Step 1: Locating the Task”
  • Look to the right side of the screen to find the ‘Available tasks’ section.
  • Identify and click on the ‘Start AutoCAD’ task.

Step 2: Selecting AutoCAD Version

Section titled “Step 2: Selecting AutoCAD Version”
  • Use the ‘Select a version’ dropdown to choose the AutoCAD version you want to start, such as AutoCAD 2025.

Step 3: Selecting an Argument

Section titled “Step 3: Selecting an Argument”
  • In the ‘Select an argument’ field, the arguments for the AutoCAD product are set. A new task starts with the arguments for plain AutoCAD. Picking another version resets the arguments to plain AutoCAD.

Step 4: Advanced Options

Section titled “Step 4: Advanced Options”
  • If required, toggle on the ‘Advanced’ switch.
  • In the ‘File path to AutoCAD executable’ field, the default path will be provided. If you need to change this, click the folder icon and navigate to the AutoCAD executable file.
  • Under ‘Arguments,’ add any command-line arguments you need. A new task starts with /product ACAD /language “en-US”. For Civil 3D or Plant 3D, use the arguments for that product instead.

Step 5: Starting AutoCAD

Section titled “Step 5: Starting AutoCAD”

Once all settings are correctly configured, initiate the ‘Start AutoCAD’ task to open the program with the selected options.

Important Notes

Section titled “Important Notes”
  • Make sure that you have the necessary licenses for the specified AutoCAD version.
  • Custom arguments are for advanced users. If you’re unsure, it’s best to stick with the default settings.
  • The startup process might vary based on the version of AutoCAD and the specifications of your device.
